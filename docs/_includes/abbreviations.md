*[PETSCII]: Commodore's 8-bit character encoding (distinct from ASCII and Screen Codes)
*[KERNAL]: Commodore's ROM-resident operating system jump table ($FF81–$FFF3)
*[VIC-II]: Video Interface Chip II ($D000–$D02E on C64 and C128)
*[VIC-I]: Video Interface Chip I ($9000–$900F on VIC-20)
*[SID]: Sound Interface Device ($D400–$D41C audio chip on C64 and C128)
*[CIA]: Complex Interface Adapter (I/O and timer chips on C64/C128)
*[TED]: Text Editing Device ($FF00–$FF3F video/sound/timer chip on Plus/4 and C16)
*[PRG]: Commodore program file beginning with a 2-byte little-endian load address
*[CRT]: Commodore cartridge image containing ROM CHIP banks
*[VICE]: Versatile Commodore Emulator (supports live debugging via Binary Monitor)
*[X-Ref]: Cross-reference — an instruction or table that reads, writes, calls, or jumps to an address
*[MCP]: Model Context Protocol — open protocol connecting AI agents to Regenerator 2000
*[TUI]: Terminal User Interface
